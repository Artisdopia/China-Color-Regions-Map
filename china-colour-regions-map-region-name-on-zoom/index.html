How to read this map

The overview groups recordings by the collection’s 15 cultural regions. Each circle represents recordings assigned to that cultural region; selecting it reveals contributing provinces. A cultural region can span several provinces, and a province can contain recordings from multiple cultural regions. Circle size represents recording counts.

Boundary geometry: Tianditu national-standard vector data, distributed as GeoJSON by GeoJSON.cn (CGCS2000 / EPSG:4490). Geometry is simplified for web display. Metadata source: ProjectAquarius/colour-regions on Hugging Face. No audio is hosted here.
